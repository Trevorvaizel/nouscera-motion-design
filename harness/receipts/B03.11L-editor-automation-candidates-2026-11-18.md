# B03.11L | Assistant-operated editor candidates | desk research, 2026-11-18

**Status:** Desk research complete; Windows execution and the NOUSCERA acceptance test **not yet performed**. This is a candidate comparison, not tool approval or a superseding production decision.

## User problem
The author does not want to learn or manually operate a professional editor simply because AI tools produce fragmented media. The assistant is expected to orchestrate source artwork, video models, sound, motion graphics, editing, revision and export. GitHub remains the continuity layer, and source image preservation remains a hard requirement.

**Research question:** Can an assistant remotely construct, revise and render an editable 720p portrait audiovisual timeline on TREVOR, with no routine user operation of the editor?

## Candidate A: WeftCut v0.8.1, provisional first trial
- Official: https://github.com/WeftCut/WeftCut
- Windows release: https://github.com/WeftCut/WeftCut/releases/tag/v0.8.1
- Main docs: https://github.com/WeftCut/WeftCut/blob/main/docs/mcp.md
- Motif authoring: https://github.com/WeftCut/WeftCut/blob/main/docs/motif-authoring.md
- Version at review: v0.8.1, published 2026-11-17; Windows executable approximately **261.5 MB decimal**. Project is MIT, actively maintained and explicitly pre-v1.
- Agent control: in-app localhost MCP server, authenticated streamable HTTP; recommended local stdio launcher `weftcut mcp`. The app's settings provide a connection entry for an MCP host. Can also be driven by a purpose-built local controller through its API, mediated by Remote Desktop Commander.
- Documented operations: import and position media, split/trim, audio tracks and role-based gain, exact clip times, keyframes and curves, captions, checkpoints and undo, exports and status polling.
- Distinctive feature: `Motifs`, deterministic time-addressed HTML/CSS/SVG/canvas/WebGL compositions as editable timeline elements. Strong fit for NOUSCERA line reveals, white typography on black, graphic metamorphoses and reusable controlled animations. Generated human movement remains external ComfyUI media.
- Review controls: agent sessions, tacks and timeline change inspection; review/undo are built in.
- Limitations: smaller newer editor and active issues involving export/decode performance and media handling; not proof of stable 720p multi-layer export on TREVOR. Windows certificate issue #135 remains open. The one-click ChatGPT desktop companion is issue #165 and **not a confirmed present connection to this ChatGPT chat**. Remote controller must explicitly invoke local MCP while TREVOR's agent is online.
- Security: bearer token and localhost binding; Motifs run under a sandbox and CSP but their code still needs review. Only work in the NOUSCERA project directory, inspect third-party code and do not enable broad remote network exposure.

## Candidate B: DaVinci Resolve 21.1 Free + ET-sec Lua console bridge
- Resolve bridge: https://github.com/ET-sec/resolve-console-bridge
- Bridge implementation: https://github.com/ET-sec/resolve-console-bridge/blob/main/docs/HOW_IT_WORKS.md
- Underlying MCP server: https://github.com/samuelgursky/davinci-resolve-mcp
- Previous Python menu-script fork `EddieRivers/davinci-resolve-mcp-free` is not a robust 21.1 recommendation because Free 21.1 moved Python scripting restrictions; use a 21.1-tested **Lua Console** approach if evaluating Resolve.
- ET-sec bridge: tested on **macOS Resolve 21.1.0.14** per author's README, with Windows installer and Windows socket code available, but Windows proof not established by the author. Uses a locally authenticated signed loopback protocol and `davinci-resolve-mcp` tool surface.
- Setup: install Resolve, Python MCP server and Lua bridge; **paste a `dofile(...)` activation line in Workspace > Console for each Resolve launch**. This is a dependency on a manual bootstrap or carefully tested UI automation.
- Available: projects/timelines, media, renders and core Resolve scripting API through bridge; Resolve itself has mature editing, Fairlight and Fusion.
- Boundaries: cannot control many color grading UI controls through the API; scripting API does not expose ordinary Edit-page keyframe animation or arbitrary Fusion inputs in a direct reliable way. Must generate/edit Fusion compositions as files or pre-render effects externally, where possible. Modal dialogs may block scripting. Community bridge can break after Resolve update and does not unlock Studio-only functions.
- Safety: bridge has signed one-use requests and loopback networking, but `call` can invoke powerful project/file-affecting API methods; the companion MCP server contains broad capabilities. Test only in a copied/sandbox project. Audit tool allowlist; its documented guard is specific to certain clients and cannot be assumed to apply in ChatGPT.

## Comparison against the actual production contract

| Requirement | WeftCut | Resolve Free + bridge |
|---|---|---|
| No-license-cost editor | Yes, MIT | Yes, freeware plus community bridge |
| Windows build available | Yes | Yes, application and bridge, but bridge's Windows path unverified |
| Direct agent timeline tools | Native MCP | Unofficial bridge to scripting |
| Agent keyframe and eased animation | Native documented tools | Major scripting limitations; custom pre-rendered FX or comp-file workaround |
| Graphic formation, text and morphs | Motifs with seekable deterministic frame(t) | Fusion powerful, but exact scripted control limited |
| Voice, SFX, music alignment | Audio layering, gain and timing documented | Mature Fairlight UI; API scope must be tested |
| Export through agent | Documented MCP jobs | Render jobs through scripting API |
| Reliability risk | Pre-v1 editor and newer renderer | Community bridge, uncertain on Windows and update-sensitive |
| Routine human UI interaction | Potentially none after setup | Lua Console startup on every launch in reference method |
| Current outcome | Research-supported candidate, no TREVOR run | Research-supported candidate, no TREVOR run |

## Acceptance experiment, same assets in both
- Use a **copy** of approved CP-05 source, never overwrite the original Krita master.
- New project: 720 x 1280, 24 fps, approximately 10 seconds; use locally controlled generated motion or a test animated image plate without pretending it proves real actor movement.
- Insert picture and an independently timed voice line plus pen sound; preserve the face and engraving in base artwork.
- Animate 'Who can I ask?' as a white-on-black separate layer. Test an exact 12-frame delay adjustment given solely by the author in chat.
- Render portrait H.264 MP4 with audio and reopen the editable project. Verify pixels, dimensions, duration, sound placement, and revision.
- Record results: runtime tool connection, failed calls, editor-required manual actions, output checksums, render timings, project re-open success and final author judgment.
- **Pass rule:** assistant can create, revise, render and reopen without routine author operation of software. An initial one-time installation prompt is acceptable only if explicitly reported. No approval based on README screenshots alone.

## Current blocker
2026-11-18: Remote Desktop Commander reports TREVOR **offline**; neither candidate has been installed or run here. No user-facing claim of passed acceptance test.

## Provisional choice and next action
Pilot **WeftCut first** because its native MCP editing, keyframes, Motifs, and in-app review most directly match the requirement of agent-owned production. Hold Resolve Free + Lua bridge as B for mature Fairlight/Fusion operations, but do not give the author an operator role. No permanent tool lock-in until the same acceptance test is executed.
