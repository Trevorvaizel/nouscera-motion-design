# NOUSCERA executable harness v0.1
This is the entry point for WH-001. Research and production are distinct. This branch supersedes November 17 handoff for the current milestone, not the original creative canon.

Run from repository root:
```
python harness/runtime/runner.py bootstrap
python harness/runtime/runner.py plan
python harness/runtime/runner.py run --registry <private-registry> --runs <local-run-root> --id replay-001 --stop-after preflight
python harness/runtime/runner.py run --registry <private-registry> --runs <local-run-root> --id replay-001 --resume
python harness/runtime/runner.py status --runs <local-run-root> --id replay-001
python -m unittest discover -s harness/runtime/tests -v
```
No model or new artwork is generated by replay. The runner checks the input identities and versions, snapshots the execution contract, and creates independent scratch output. It uses the frozen CP05 operation through a narrowly scoped adapter, not a generic scene author. An interrupted replay's scratch is retained under quarantine before retry. A failed or running receipt is not a pass. Resume requires explicit flag and identical contract/registry/code fingerprints. A lock must not be removed until the prior process is confirmed dead. No credentials or assets in public Git.

## Knowledge and instruction loading
`current.json` is the active control state. `workflows/scene-readiness.v01.json` is the executable contract; `catalog.json` maps the actual tool responsibilities. `bootstrap` emits a small canonical context packet for a fresh agent, including unresolved constraints and authority. Read historical primary decisions only as needed. No inferred approval. A model invocation must carry this packet and the task-specific contract; a text prompt alone is not enforcement.

## Scope
This version deliberately replays the last actual prepared scene. It cannot yet generate new clean plates automatically. The previous clean-plate reconstruction was approximate, and the next creative operation must use a purposefully prepared Krita/ComfyUI surface with reviewable hidden geometry. The Blender master is separate from the raster preview; native Blender parity is not proved. Cross-scene transfer and cross-model operation are separate gates, not inferred from replay. Do not add n8n until the underlying operations and handoffs are reliable. No creative approval follows from technical checks.

## Evolution
Every new operation gets an ID, version, inputs, output contract, tests, failure boundaries, receipt and promotion decision. Preserve original scripts and graph identities privately; generic code may be committed only after rights/secret review. Current state changes only after evidence and explicit approval boundaries are recorded. A new model should only receive the context required for its task; it cannot bypass the gate. See the existing knowledge policy and workflow history.

## Additional guards
Run `python harness/runtime/scene_gate.py <private-scene-manifest> --out <new-report>` to test asset readiness; nonzero status is intentional when evidence is missing. Read [scene preparation contract](SCENE_READINESS.md).
`fixture_transfer.py --out <new-dir>` exercises the reusable fixed/rigid layer primitive using Pillow. Embedded Python may require explicitly adding the runtime directory to sys.path. This is not a creative scene transfer.
The local private registry and runtime snapshots must be restored separately on another device; the public repository contains only generic code, contracts and sanitized summaries. See the dated receipt for actual test evidence.

## Cold-model handoff
Run `python harness/runtime/handoff_check.py prepare --out <new-dir>` to create a task packet. Invoke a trusted, authenticated model in read-only mode with the packet's request.txt; do not supply private asset paths or grant creative execution. Run `python harness/runtime/handoff_check.py evaluate --answer <response.json> --provider-exit <code> --out <new-report>`; provider failure and nonconforming answers fail closed. This checker is scoped to WH-001. See [WH-001 execution receipt](../receipts/WH-001-WORKFLOW-HARNESS-2026-11-24.md). A successful synthetic answer is not a real model test.
