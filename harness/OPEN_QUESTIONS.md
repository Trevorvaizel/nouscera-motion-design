# Open questions and uncertainty register

A question is closed only when an artifact, decision, or test resolves it; mark who closed it and point to the evidence. Do not invent an answer because a downstream file needs one.

## Do not confuse uncertainties

An unresolved artistic choice is not the same as missing empirical evidence. A production risk is not the same as ambiguity in the author's claim. Keep each in the correct register.
