# Nouscera Motion Design

**An AI-first cinematic explainer studio, built brick by brick.**

This repository is a *working harness*: the place where research, authored intent, decisions, creative alternatives, experiments, rejected takes and revised methods remain connected to the film they inform.

The current test story is: **"Having more information does not necessarily mean having more direction."**

The engraved black-and-white astronaut illustration is a **style benchmark, not the film's subject**. The intended moving-image grammar involves forms emerging from blackness, acquiring convincing depth, transforming, and returning to the void. Illustrations and AI video are the primary production route. Editable 3D is not a goal; 2.5D or compositing may be used only where justified.

## The operating principle

**Meaning is authored. Images are proposed. Motion is directed. Generated results are selected and tested. Learnings revise the method.**

Research does not automatically become doctrine. A visually impressive result does not establish explanatory success. The human author approves changes to the central thought and any promotion from candidate to adopted rule.

## Publication and source boundary

This is a **public GitHub repository**. Do not upload private conversations, unrelated project files, confidential KIRA source materials, third-party reference imagery, API credentials, purchased assets or video outputs with unclear rights. Public research drafts should clearly identify their provisional status and cite their sources. The Git history records edits but does not replace decision explanations.

## Versioning

Use one small decision-bearing change at a time. A change is complete only when its artifact, reasoning, acceptance status, and next open question are recorded. Prefer pull requests for consequential changes once the harness is established.
